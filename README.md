# TaskFlow

TaskFlow is a native Android app (Jetpack Compose) for capturing, organizing, and scheduling tasks using microphone or manual entry. It includes Gemini-oriented settings, swipeable task cards, reminders, and attachment handling for audio and images.

## Features
- Microphone or manual task creation with priority, category, and due date/time.
- Swipeable cards for quick triage plus detail editing with status, reminders, and attachments.
- Image analysis shortcut to seed tasks and audio attachments for context.
- Settings screen for API key entry, agent list refresh, and copyright/version info.
- Notification reminders for due work with morning-friendly defaults.

## Running locally
Open the project in Android Studio Iguana or newer with Android SDK 34+. Build and run the `app` module on a device or emulator (API 26+).
